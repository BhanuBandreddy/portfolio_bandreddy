# Bhanu Harish Bandreddy — Executive Portfolio

Portfolio website for Bhanu Harish Bandreddy, Vice President — Product Innovation & AI Solutions.

The site presents enterprise product work across insurance distribution, CRM transformation, merchant onboarding, broker operations, learning platforms, product configuration and multi-agent AI systems.

## Live site

[bhanu-trajectory.bhanubandreddy.chatgpt.site](https://bhanu-trajectory.bhanubandreddy.chatgpt.site)

## Included

- Responsive executive portfolio homepage
- Work directory with nine case studies
- Individual dynamic case-study routes
- Product and transformation operating model
- Professional profile and career evidence
- Three embedded architecture demonstrations with original soundtracks

## Technology

- React 19
- Next.js 16-compatible application structure
- Vinext and Vite
- TypeScript
- Tailwind CSS
- Cloudflare Worker build output

## Local development

```bash
npm ci
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```

## Repository notes

Portfolio content and media are provided for presentation purposes. Client-confidential information, production data and commercial terms are intentionally excluded.

The production video and image assets are referenced from the live portfolio URL to keep the GitHub repository lightweight and within normal source-control limits.
